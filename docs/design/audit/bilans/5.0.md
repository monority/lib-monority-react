## Architecture

- Modèle : `packages/ui/src/lib/design-config.ts`.
- Provider : `packages/ui/src/providers/design-provider.tsx`.
- Export public : `DesignProvider`, `DesignConfig`, `resolveDesignConfig`, `DESIGN_PRESETS` et `designConfigToJSON`.
- Le moodboard utilise `DesignProvider` et fournit un vrai customizer dans la barre existante.
- Les axes sont résolus en variables CSS, sans composants dupliqués :
  - `--mr-brand-hue` / `--mr-brand-chroma` pour l’accent ;
  - `--mr-control-accent*` pour les contrôles ;
  - `--mr-chart-1..5` pour les données ;
  - `--mr-radius-*` pour la géométrie ;
  - `--mr-spacing-*` pour l’espacement ;
  - `data-density` et les gaps de layout pour la densité.
- Les composants Button, Checkbox, Switch, RadioGroup et Tabs consomment les variables de contrôle partagées.

## Customizer

Le moodboard expose des groupes séparés pour Theme, Brand, Accent, Components, Charts, Radius, Spacing et Layout. Chaque changement est visible immédiatement dans les panneaux. La configuration est persistée dans `monority-design-config` et peut être copiée en JSON.

## Accessibilité

- Axe-core : 0 violation sur les panneaux moodboard.
- Le changement de component color est appliqué aux contrôles réels et ne modifie pas les contrastes de statut.
- Focus, keyboard, disabled et selected states restent fournis par les composants existants.
- Les presets de couleur sont des valeurs sémantiques accessibles, pas des couleurs injectées dans les composants.
